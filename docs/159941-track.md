# 159941（纳指100 ETF） hourly 盯盘

## 行为

- **标的**：深交所 ETF `159941`（跟踪纳斯达克100），行情来自腾讯 `qt.gtimg.cn`。
- **频率**：每小时整点后约 48 分执行一次（Cursor 自动化 cron：`48 * * * *`；GitHub Actions 工作日每小时 `:48 UTC`）。
- **交易时段**（北京时间，含法定节假日休市判断）：
  - 上午 09:30–11:30
  - 下午 13:00–15:00
- **输出**：`data/159941/yyyy-MM-dd.xlsx`，同一天追加行；同一自然小时重复运行会**更新**该行而非重复插入。

## 本地 / 自动化运行

```bash
bash scripts/run_track_and_commit.sh
```

非交易时段默认跳过；测试拉取：

```bash
python3 scripts/track_159941.py --force
```
