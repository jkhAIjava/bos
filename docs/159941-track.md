# 159941（纳指 100 ETF）工作日盯盘记录

本仓库通过 **GitHub Actions** 在 A 股交易日、交易时段内定时拉取 **sz159941**（易方达纳指 100ETF）行情，将**实时涨跌幅**等字段写入 `data/159941/yyyy-MM-dd.xlsx`。同一天多次运行会在**同一文件内按「小时段」追加或更新**（同一小时只保留一行最新快照）。

## 交易时段（北京时间）

- 上午：09:30–11:30  
- 下午：13:00–15:00  

非工作日或非交易时段运行脚本会打印 `skip` 并正常退出，不写表。

## 定时规则

工作流： [.github/workflows/track-159941.yml](../.github/workflows/track-159941.yml)

- 工作日 UTC `01:48–07:48` 对应北京时间 **09:48–15:48** 每小时一次（与常见自动化 cron 的 `:48` 对齐）；午间休市时脚本自动跳过。  
- 另在 UTC `03:00`、`07:00` 各跑一次，对应北京时间 **11:00、15:00**，补采午间收盘前与全天收盘附近整点。  

也可在 GitHub Actions 页面手动 **Run workflow**（`workflow_dispatch`）。

## Excel 列说明

| 列名 | 含义 |
|------|------|
| 记录时间 | 本次写入的北京时间 |
| 小时段 | `YYYY-MM-DD HH:00`，同日同小时更新同一行 |
| 现价 / 昨收 / 涨跌额 / 涨跌幅(%) | 来自腾讯行情接口 |
| 开盘价 / 行情时间 | 辅助字段 |

## 本地运行（可选）

```bash
cd /path/to/bos
pip install -r scripts/requirements-track.txt
python3 scripts/track_159941.py
```

仅在工作日交易时段内会更新 `data/159941/` 下当日 xlsx。

## 提交说明

CI 中由 `scripts/run_track_and_commit.sh` 将 `data/159941/*.xlsx` 的变更提交并推送到 **master**（需仓库 `contents: write` 权限）。

**说明**：行情数据来源于公共接口，仅供个人记录参考，不构成投资建议。
