# 159941（纳指100 ETF） hourly 盯盘

## 行为说明

- **标的**：深圳 ETF `159941`（纳指100 相关）
- **频率**：每个**交易日**、**A 股连续竞价时段**内执行（09:30–11:30、13:00–15:00，Asia/Shanghai）
- **输出**：`data/159941/yyyy-MM-dd.xlsx`，同一天多次运行**追加一行**，不覆盖历史
- **行情源**：腾讯 `qt.gtimg.cn`（无需 API Key）

## 本地运行

```bash
pip install -r requirements-track.txt
python scripts/track_159941.py          # 仅在交易时段写入
python scripts/track_159941.py --force  # 测试用，忽略时段
```

## GitHub Actions 定时

工作流：`.github/workflows/track-159941.yml`

- Cron 对应北京时间 **周一–周五** 在交易时段附近每小时 **:48** 触发
- 脚本内仍会校验「中国工作日 + 交易时段」，非开盘会自动跳过
- 有新增数据时自动 commit 并 push 到默认分支

## Cursor 自动化

若已配置每小时运行的 Cursor Automation，可在该 automation 中执行：

```bash
pip install -r requirements-track.txt && python scripts/track_159941.py && git add data/159941 && git commit -m "..." && git push
```

与 GitHub Actions 二选一或并存均可；并存时同一小时可能产生重复行，可按需只保留一种调度方式。
