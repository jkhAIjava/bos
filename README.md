# 159941（纳指 ETF）工作日盯盘记录

本仓库通过定时任务在** A 股交易日、交易时段**拉取 **sz159941**（易方达纳斯达克 100ETF，跟踪纳斯达克 100）的行情，并将**涨跌幅等字段**写入按日区分的 Excel，同一天内**按小时档追加**；若同一小时档多次运行则**更新该小时行**（避免重复行）。

## 数据文件

- 路径：`data/159941/yyyy-MM-dd.xlsx`
- 列：记录时间、小时段、现价、昨收、涨跌额、涨跌幅(%)、开盘价、行情时间

## 交易时间判定（北京时间）

- 使用 `chinese-calendar` 判断是否为**中国大陆工作日**（含调休补班）。
- 仅在 **9:30–11:30**、**13:00–15:00** 内写入；非交易时段运行会 `skip`、不改动文件。

## 定时方式（双保险）

1. **Cursor 自动化**：cron `48 * * * *`（每小时 `:48` UTC）执行 `scripts/run_track_and_commit.sh`，在交易窗口内拉数并提交到 `master`。
2. **GitHub Actions**：`.github/workflows/track-159941.yml` 在工作日 UTC 对齐时段调度，并额外在 UTC `3:00`、`7:00`（对应北京时间 11:00、15:00）补采，避免仅 `:48` 触发时漏掉 11:00、15:00 整点档。

## 本地执行

```bash
pip install -r scripts/requirements-track.txt
python3 scripts/track_159941.py
```

交易时段外会直接退出并打印 `skip`。

## 脚本说明

| 文件 | 作用 |
|------|------|
| `scripts/track_159941.py` | 请求腾讯行情接口 `sz159941`，写入/更新当日 xlsx |
| `scripts/run_track_and_commit.sh` | 安装依赖、检出 `master`、运行脚本、若有变更则 commit/push |

行情来源为公开接口，仅供个人记录参考，不构成投资建议。
