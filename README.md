# 159941（纳指 100 ETF）盯盘记录

本仓库在 **A 股交易日、沪深 ETF 连续竞价时段** 按小时采集 **sz159941**（深交所「纳指 ETF」）的行情，并将结果写入 Excel，推送到 `master`。

## 产出路径与文件命名

- 目录：`data/159941/`
- 文件名：`yyyy-MM-dd.xlsx`（按北京日自然日区分）
- 同一天的所有采样写入**同一个文件**；以「小时段」`yyyy-MM-dd HH:00` 为键：**该小时第一次写入为追加，同小时内再次运行则覆盖更新该行**（避免重复行）。

## 表头字段

| 列名 | 说明 |
|------|------|
| 记录时间 | 脚本执行时的北京时间 |
| 小时段 | `yyyy-MM-dd HH:00`，用于去重/更新 |
| 现价 | 最新价 |
| 昨收 | 昨收价 |
| 涨跌额 | 涨跌额 |
| 涨跌幅(%) | 相对昨收的涨跌幅（%） |
| 开盘价 | 当日开盘价 |
| 行情时间 | 行情源返回的时间字段 |

行情来源：腾讯行情接口 `qt.gtimg.cn`（标的 `sz159941`）。

## 何时执行（交易日）

使用 [chinese_calendar](https://pypi.org/project/chinese-calendar/) 判断 **中国工作日**（调休上班算工作日；法定节假日与周末休市则跳过）。

仅在以下 **北京时间** 窗口内写入数据，其余时间运行脚本会直接跳过：

- 上午：09:30–11:30  
- 下午：13:00–15:00  

说明：触发器可能安排在每小时一次，但脚本只在上述窗口内落盘。

## 定时任务

1. **GitHub Actions**（`.github/workflows/track-159941.yml`）  
   - 工作日按 UTC 调度，与「每小时采集」对齐；并在临近午盘/收盘的整点增加补采，避免 `:48` 触发时已收盘而漏掉最后一根小时段。

2. **Cursor 自动化**（cron `48 * * * *`）  
   - 每小时调用 `scripts/run_track_and_commit.sh`，逻辑与 Actions 一致。

## 本地/manual 运行

```bash
bash scripts/run_track_and_commit.sh
```

脚本会安装 `scripts/requirements-track.txt` 中的依赖，切换到 `master` 拉取最新后执行采集，若有 `data/159941/*.xlsx` 变更则提交并推送。
